# Cohere

A local-first LaTeX writing desk for macOS. A library of projects, house templates,
a syntax-aware editor with compile diagnostics, an integrated PDF view and versioned
snapshots — all on your own machine, with no accounts and no network.

Built with Tauri 2 (Rust) · React 18 · TypeScript · CodeMirror 6 · pdf.js, compiling
through `latexmk` with the machine's TeX Live.
