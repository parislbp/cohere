# Cohere v0.2.0

*A local-first LaTeX writing desk for macOS.*

Cohere keeps a library of LaTeX projects on your Mac, gives each one an editor with a compiled PDF beside it, and never sends anything anywhere. It compiles with the TeX installation already on the machine (MacTeX / TeX Live) through `latexmk`.

---

## 1. Installing and running it

**Install:** download `Cohere.dmg` from the [latest release](https://github.com/parislbp/cohere/releases/latest), open it, drag Cohere to Applications. The app is signed with a Developer ID and notarized by Apple, so it opens without warnings. Apple Silicon, macOS 12 or newer.

**Updates:** Cohere checks GitHub for a newer release when it starts (Settings › About › *Check for updates at launch* turns this off — it is the only network request the app makes on its own). When one exists, a dialog shows the release notes; **install and relaunch** downloads it, verifies its signature against the key built into the app, swaps the bundle and restarts. *Later* hides it until the next launch. You can also ask any time: Settings › About › **check now**, or ⌘K → *Check for updates*.

**TeX:** Cohere compiles with the TeX Live already on the Mac (MacTeX, BasicTeX, Homebrew). If none is found you are offered **Install TeX for Cohere** — a private, portable TeX Live (scheme-basic plus exactly the packages the templates use, ≈ 420 MB) inside Cohere's data folder. Nothing is added to your PATH or `/usr/local`; *remove* in Settings › Compiler deletes it again.

**Remove Cohere:** Settings › About › **remove Cohere…** offers to export every project as a zip bundle, then moves the app, the data folder and Cohere's per-app system files to the Trash and quits. Nothing is deleted outright.

**Developing:**

```bash
cd ~/projects/cohere
make dev        # = tauri dev; uses its own library in …/com.cohere.desk.dev so it never touches the installed app's projects
make dev-mock   # browser-only UI at http://localhost:1420/?mock=1 with an in-memory backend
make check      # typecheck · lint · vitest · cargo test
```

Data lives in `~/Library/Application Support/com.cohere.desk/` (`….dev` for `make dev`). To run against a scratch data directory: `COHERE_DATA_DIR=/tmp/cohere-data make dev`. Development builds never check for updates.

A browser-only preview with an in-memory backend (no TeX, no files written) is `npm run dev:mock` → `http://localhost:1420/?mock=1`.

Requirements: macOS 12+, MacTeX or TeX Live with `latexmk` (Cohere looks in `/Library/TeX/texbin`, `/usr/local/texlive/<year>/bin/*darwin`, Homebrew, then `PATH`; Settings › Compiler shows what it found and lets you point it elsewhere).

## 2. Library

The first screen. One row per project; nothing scrolls — when rows do not fit, a pager appears.

| element | what it does |
|---|---|
| **search** | opens a centred filter bar; typing matches title, topic and template; Esc closes. ⌘F |
| **new** | new-project dialog (see below). ⌘N |
| row → title | opens the project (double-click the row also works); long titles and topics clip with an ellipsis — hover for the full title |
| checkbox (appears on hover) | selects rows; the header checkbox selects the page; a small bar appears with archive / delete / clear |
| type glyph | the template the project was made from, each in one of the theme's five accents — hover for its name (Blank · Project · Brief · Periodical · Paper, 1-column · Paper, 2-column · Minimal) |
| Title · Topic · Modified | click a header to sort; Modified shows whole days ("today", "3 days ago"); hover for the exact time and the creation date |
| ★ | favourite a project; click the column header to cycle all → favourites → everything else |
| hover actions (right end of a row) | **download bundle** (.zip of all source files, texref-compatible) · **download PDF** (latest compiled) · **rename / topic** · **archive** or **unarchive** · **delete** |
| footer left | `projects` / `archived` toggle with counts — archived projects are dimmed and cannot be opened until unarchived |
| footer right | match count while searching |

**Delete** asks first, then moves the whole project folder to `<data dir>/.trash/` — nothing is destroyed; recover by moving the folder back into `projects/`.

### New project

1. Pick a template. Hover a card for its description.
   - **Blank** — one `main.tex` (article, title, one section, a `.bib`).
   - **Project** — report class: title page, abstract + reading guide, contents, numbered chapters, appendices, bibliography. The house style from the MTM document.
   - **Brief** — no cover; title block, inline abstract, numbered sections, appendices.
   - **Periodical** — two columns, spanning title and abstract.
   - **Minimal** — one-line title, sections, references.
   - **Paper (two columns)** — the house paper style: warm sheet, paneled abstract spanning both columns, hairline section rules with accent numbers, framed figures, a faded version number in the foot. Default LaTeX fonts, like the other templates.
   - **Paper (one column)** — the same style at full measure; put `\unitpage` before a section to start it on a fresh page.

   The picker shows five templates at a time; the ⟨ ⟩ arrows on either side step to the next page.
2. Title (required), Topic (optional; shows in the Library), Subtitle where the template uses one.
3. Structure: number of chapters/sections, sub-units in each, appendices (fields a template does not use are greyed out). Each file is created and already `\input` in `main.tex`. The first unit contains a worked example of the house table, equation, figure and citation to copy from.
4. **create** opens the editor. An empty title becomes “Untitled Project”, then “Untitled Project 2”, ….

Every project is also a valid texref project (`tex.json`, `Makefile`), so an exported bundle works with the `tex-*` shell commands.

## 3. Editor

Three columns: **sidebar · source · PDF**. Drag the thin dividers to resize; double-click one to reset. ⌘1 (or the panel icon at the right end of the tabs row) hides the sidebar. Each sidebar section folds when you click its header; folded headers stack at the top or bottom so the open sections take all the room, and the dividers between open sections drag (a grip appears on hover).

The window's traffic lights are drawn by Cohere in the theme's colours and appear only while the cursor is over the top bar (they replace the brand mark in the top-left corner); ⌥-click the third one for full screen.

### Sidebar

**Files** — the project tree. Header icons: new file, new folder, add files (copies them in), reveal in Finder (opens the project's `src/` folder with the current file selected), export project (.zip). Drag a file or folder onto a folder (or onto the empty area for the root) to move it; hovering a closed folder opens it. Drop files from Finder onto the tree to add them to the folder under the cursor. Click a folder to select it as the target for new items. Right-click any item for: new file/folder here, add files, set as main file (`.tex`), rename, delete. The `main` badge marks what compiles; it cannot be deleted. Unsaved files show a dot. Images open as a preview.

**Outline** — the sections of the open file (`\part` … `\subparagraph`; starred ones marked; appendix chapters marked `app`). Click to jump. The section holding the cursor is highlighted. The book icon in the header (⌘⇧0, on by default) shows the **whole document**: Cohere follows `\input`/`\include`/`\subfile`/`\import` from the main file in document order, marks where each file starts, and clicking any heading opens that file at the right line. Inputs it cannot find are counted at the bottom.

**Outputs** — folded when a project opens (click the header to show it); the latest `main.pdf` (pages · size · when; hover for engine and duration) with **log**, **reveal in Finder** and **export**. Below the divider, **versions**: the camera freezes the current PDF together with a zip of every source file. Hover a version for export (PDF or bundle), rename/note, delete.

### Source

Tabs for open files (middle-click or × closes; ⌘W). The right end shows saving state. Autosave writes 0.8 s after you stop typing (Settings › Editor › Autosave), and always on compile, blur and close. Writes are atomic.

Editing:

- LaTeX colouring: comments, commands, sectioning, environments, math (inline, display, environments), verbatim, labels/refs/cites, options, braces — colours follow the theme.
- Completions: type `\` for commands (with snippets for arguments), `\begin{` for environments, `\ref{`/`\cite{` for labels and bibliography keys from your `.bib` files, `\input{`/`\includegraphics{` for project files. Enter after `\begin{x}` inserts `\end{x}`.
- **The `@` palette**: at the start of a word, type `@` and a few letters — `@table`, `@figure`, `@equation`, `@align`, `@section`, `@itemize`, `@cite`, `@ref`, `@definition`, `@listing`, `@todo`… — and the block is inserted in the house style with tab-stops (⇥ moves through the fields, and `@fig`, `@eq`, `@sec` are shortcuts). Forty-odd blocks in v0.1; the list is fixed for now and lives in `codemirror/snippets.ts`.
- Fold environments and sections from the gutter. ⌘F opens search/replace. Brackets match and auto-close; `$` auto-closes too.
- Formatting: select text (or just put the cursor in a word) and press ⌘B for `\textbf{…}`, ⌘I for `\emph{…}`, ⌘U for `\underline{…}`, ⌘⇧C for the house `\code{…}` (`\texttt` in Blank projects). Pressing the same key on an already-wrapped selection unwraps it.
- Spell check uses the system dictionary (toggle in Settings).

### Compile

**compile** at the left of the PDF toolbar, or ⌘⇧↩. Files are saved first. While running, the button becomes **stop** and a thin bar runs across the top of the PDF. When done, a chip shows `✓ 1.9 s`, `1 error · 2 warn` or `3 warnings`; click it (or ⌘⇧M, or the counts in the status line) to open the **problems** panel:

- rows show `file:line  message` with TeX's context; click to jump to the line (the file opens if needed);
- filter by errors / warnings / notes (overfull boxes and the like);
- the **log** tab streams latexmk's output live; the Outputs card opens the full `main.log`.

In the editor, error lines get a red gutter marker and a red squiggle; hover for the message.

LaTeX runs in nonstop mode, so a document with errors usually still produces a PDF — the PDF pane says "built with 1 error". If no PDF was produced, the previous one stays and the banner says so.

### PDF

Pages render lazily at screen resolution. Toolbar: page up/down and a page box (type a number, Enter), zoom −/+, the zoom label (click for 100%), **fit width**, **fit page**, **export**. ⌘-scroll zooms; ⌘= / ⌘− / ⌘0 when the PDF has focus. After each compile the PDF reloads in place and keeps your position.

### Status line

`errors · warnings` (click for problems) · cursor line · approximate word count of the file (prose only) · engine.

## 4. Settings (⌘,)

| section | controls |
|---|---|
| **Appearance** | theme — **Paper** (warm light), **Mist** (cool light), **Ink** (warm dark), **Graphite** (cool dark); animation speed — off · slow · normal · fast (off removes every transition); tooltips on/off and delay |
| **Editor** | font size and family, tab size, wrap, line numbers, current-line highlight, bracket matching, auto-close, completions, spell check, autosave delay, compile on save |
| **Compiler** | engine — pdfLaTeX · XeLaTeX · LuaLaTeX (greyed when the installation lacks it); shell escape (off; only for documents you trust); SyncTeX; the TeX installation card with **re-detect**, **install TeX** (when none is found) or **remove** (for Cohere's private install); a bin-directory override |
| **About** | version, **updates** (check at launch · status · check now), data directory (reveal), templates, shortcut list, **remove Cohere…** |

The theme and animation speed are also in the top-right menus on every screen.

## 6. Where things are

```
~/Library/Application Support/com.cohere.desk/
├── settings.json
├── projects/<id>/
│   ├── project.json       title, topic, template, dates, archived, main file
│   ├── src/               your files — only what LaTeX needs (main.tex, chapters/ or sections/, references/, figures/); this is what "download bundle" zips
│   ├── build/             latexmk's working files
│   ├── output/            main.pdf · main.log · meta.json
│   └── versions/<id>/     version.json · main.pdf · src.zip
└── .trash/                deleted projects
```

With *Install TeX for Cohere*, the distribution lives at `texlive/tl/` inside the same folder (`bin/universal-darwin/` holds `latexmk`, `pdflatex`, `xelatex`, `lualatex`, `biber`, `tlmgr`).

## 7. Known limits in 0.2.0

- Renaming a file does not rewrite `\input{…}` references in other files (do it by hand).
- No click-to-jump between PDF and source.
- Versions can be exported and deleted, not previewed or restored in place.
- Files can be added with the picker or dragged within the tree, not dropped from Finder.
- Apple Silicon only; no Intel build.
- Install TeX for Cohere needs the network once (CTAN mirrors) and adds only the packages the built-in templates use — `tlmgr install <pkg>` from its `bin/` directory adds more.
- New projects no longer carry the texref CLI files (`Makefile`, `README.md`, `.gitignore`, `tex.json`); a "CLI-compatible bundle" export option will bring them back on demand.

## 8. If something goes wrong

| symptom | look here |
|---|---|
| "no TeX installation found" | Settings › Compiler › **install TeX** (private TeX Live), or re-detect after installing MacTeX, or set the bin directory (e.g. `/Library/TeX/texbin`) |
| compile "failed", no PDF | problems panel → the first error; the log tab shows latexmk's reasoning; Outputs card → full `main.log` |
| a package is missing | MacTeX: `sudo tlmgr install <package>`; TeX for Cohere: `"~/Library/Application Support/com.cohere.desk/texlive/tl/bin/universal-darwin/tlmgr" install <package>` — then compile again |
| "could not reach GitHub to look for updates" | offline, or GitHub is down — nothing else is affected; check again later or download the DMG by hand |
| the update dialog never appears though a release exists | Settings › About › check now; development builds (`make dev`) never check |
| text you typed is gone | it is not: autosave writes 0.8 s after typing stops and on blur — check `src/` in the data directory |
| a project vanished | Library footer → archived; otherwise `<data dir>/.trash/` |
| the window is on another Space | ⌘-Tab to Cohere |
| something is badly wrong | Settings › About › remove Cohere… (export first), then reinstall from the latest DMG; your projects stay in the exported bundles |
